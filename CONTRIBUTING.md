# Contributing to Modelify

[English](CONTRIBUTING.md) · [简体中文](CONTRIBUTING.zh-CN.md)

Thanks for your interest in Modelify.

This public repository focuses on documentation, examples, integrations, and community feedback rather than the complete production source code.

## Good contributions

We welcome:

- Documentation fixes
- Clearer examples
- Integration ideas
- Reproducible bug reports
- Suggestions for e-commerce workflows
- Feedback on developer experience

## Before opening a pull request

1. Keep changes focused.
2. Do not include credentials, private customer data, or proprietary Modelify production code.
3. Prefer examples that are easy to understand and maintain.
4. If a change is substantial, open an issue first to explain the use case.

## Issues

When reporting a problem, include:

- What you were trying to do
- What happened
- What you expected
- Steps to reproduce, when applicable

Security vulnerabilities should follow [SECURITY.md](SECURITY.md) and must not be disclosed through public issues.
