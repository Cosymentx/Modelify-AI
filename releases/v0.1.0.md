# v0.1.0 — Fashion AI Starter Pack

The first public Modelify resource release is focused on practical AI fashion workflows for e-commerce teams.

## Included

- Fashion E-commerce AI Cookbook
- Fashion Prompt Library
- Source Image Preparation Guide
- Shopify Product Image Workflow
- AI Fashion Troubleshooting Guide
- Real Modelify generation examples
- English-first documentation with Simplified Chinese versions alongside

## What this release is for

This starter pack is designed to help fashion sellers, brands, and builders get more consistent results from AI product photography workflows — from preparing source images to creating catalog, lifestyle, and campaign-ready outputs.
