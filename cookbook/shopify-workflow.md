# Shopify Product Image Workflow

[English](shopify-workflow.md) · [简体中文](shopify-workflow.zh-CN.md)

A simple workflow for using AI-generated fashion images in a Shopify product catalog.

## 1. Start from the product master image

Keep one reliable source image for each SKU or variant.

Do not overwrite the original product photography with generated assets.

## 2. Define a consistent image set

For example:

```text
01-front
02-three-quarter
03-side
04-lifestyle
05-detail
```

Not every SKU needs all five, but using a repeatable naming and composition system makes the catalog feel more professional.

## 3. Generate in small batches

Generate a few controlled options first.

Compare:

- Color
- Hem length
- Sleeve length
- Neckline
- Pattern placement
- Logos
- Material appearance
- Fit and silhouette

Regenerate when important product details drift.

## 4. Keep aspect ratios consistent

Consistency across the collection often matters more than choosing the most dramatic crop for every individual image.

Pick a standard storefront ratio and use it across the catalog whenever possible.

## 5. Optimize before publishing

Before upload:

- Check image dimensions
- Compress appropriately
- Keep enough quality for zoom
- Use meaningful alt text
- Avoid unnecessary metadata
- Confirm mobile cropping

## 6. Preserve traceability

Maintain a simple relationship between:

```text
SKU → source image → generated assets → published Shopify media
```

This makes replacements, corrections, and future regeneration much easier.

## 7. Human review remains important

AI imagery can look convincing while still changing small product details.

For commerce use, always review important attributes before publishing.
