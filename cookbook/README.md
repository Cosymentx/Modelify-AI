```text
      │
      ▼

      │
      ▼

      │
      ▼
Check garment fidelity
      │
      ▼

      │
      ▼

```

## What to optimize for

For fashion e-commerce, the best-looking image is not always the best product image.

Prioritize:

1. Garment fidelity
2. Clear silhouette
3. Accurate color
4. Consistent lighting
5. Natural model pose
6. Consistent framing across a product set

## Suggested image set per SKU

A practical product page can benefit from:

- 1 clean front-facing hero image
- 1 three-quarter model view
- 1 side or detail-oriented view
- 1 lifestyle-oriented image
- 1 close-up for important garment details

You do not need every image for every product. Consistency matters more than volume.
